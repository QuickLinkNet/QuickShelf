# Changelog

## 1.0.0

- Cockpit for a document and media archive: overview, file search (names and contents), viewer, gallery, clean-up assistant, activity calendar, watch list, sort inbox with undo.
- Password login, first-run setup wizard, exposure self-check.
- No-Docker release package (`npm run release`), try-out server, demo archive (`npm run demo`).
- English and German UI.
- GitHub Actions for CI and releases.
